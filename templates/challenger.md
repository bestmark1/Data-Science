# Претендент: спецификация сравнения

Блок вставляется в пре-регистрацию и опечатывается вместе с ней. С двадцать
первого кейса `preflight` отказывает без него. Правило — раздел «Претендент» в
`AGENTS.md`: претендент засчитывается по интервалу парной разницы на одних
строках и объявленному минимальному улучшению, бюджет подбора равен, в кейсе
подбора нет ни у кого.

Если претендента нет, объявляется это, с причиной:

Текст проверяется как записан: без управляющих знаков по краям и внутри.
Длинный текст — блоком `>-`, а не `>`: `>` оставляет перевод строки в конце.

```yaml
project: <имя каталога кейса>
challenger:
  none: "<почему в этом кейсе новый метод не сравнивается>"
```

Полная спецификация. Строки — в кавычках: `version: 2.6` без кавычек YAML
прочтёт числом, и форма его отвергнет.

```yaml
project: <имя каталога кейса>
challenger:
  challenger:                 # претендент
    name: "<метод>"
    version: "<версия пакета>"
    checkpoint: "<какие именно веса>"
    settings: {<параметр>: <значение>}   # явно, не «умолчания версии»
    preprocessing: "<что делается с признаками>"
  incumbent:                  # действующий метод
    name: "<метод>"
    version: "<версия пакета>"
    settings: {<параметр>: <значение>}
    preprocessing: "<что делается с признаками>"
  metric:
    name: average_precision   # roc_auc | average_precision | brier | log_loss
    definition: "<точное определение и реализация>"
  min_improvement: 0.0        # δ ≥ 0: улучшение, ниже которого преимущество не засчитывается
  tuning: none                # в кейсе подбора нет ни у кого
  split: "<окна и резерв>"
  bootstrap:
    confidence: 0.95          # доля в (0, 1)
    method: "<перцентильный, парный, …>"
    unit: "<строка, объект, группа — по структуре зависимости>"
    repeats: 400
    seed: 0
  window_predictions: "<как получены прогнозы по окнам: на чём обучена модель каждого окна>"
  on_failure: "<что при нехватке памяти, пределе объёма, отказе; другая версия по результату не берётся>"
  measurement_order: "<одно итоговое измерение обоих на резерве, одним обращением>"
  license: "<лицензия кода, весов и выходов и разрешение на использование>"
```

`preflight` проверяет форму этой записи, а не исполнение сравнения.
