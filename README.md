# dsx

Личный переносимый инструментарий дата-сайентиста. Ядро пишется один раз, новая
работа или новая задача добавляет только конфигурацию проекта-экземпляра.

Концепция: [CONCEPT_V2.md](CONCEPT_V2.md). Планы: [docs/plans/](docs/plans/).

## Установка

```bash
uv venv
uv pip install -e ".[dev]"
```

## Правила, которые нарушаются однократно и необратимо

**Рабочие проекты в этом репозитории не хранятся.** `projects/` содержит только
учебные и публичные экземпляры. Конфигурация рабочего проекта содержит имена
таблиц и колонок работодателя — она живёт в отдельном каталоге вне этого
репозитория и подключает `dsx` как зависимость.

**Данные не коммитятся.** В репозитории лежит манифест источника с контрольными
суммами и скрипт загрузки. Учебный датасет Olist распространяется под лицензией
CC BY-NC-SA 4.0 и не подлежит перераспределению.

**Журнал разделён.** `knowledge/portable/` — обобщённые уроки, переносятся между
местами работы. `knowledge/local/` — конкретика места, в git не попадает.

## Граница пакета

Ядро (`src/dsx/`) не импортирует ничего из `projects/`. Зависимость односторонняя
и проверяется тестом, а не дисциплиной.
