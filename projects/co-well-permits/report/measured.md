# Колорадо: будет ли скважина построена до истечения разрешения

## Заключение

модель ранжирует лучше правила «постоянная оценка 0.701», но калибрована хуже: порядок верен, обещанные вероятности — нет Срок здесь взят ИЗ ИСТОЧНИКА, а не назначен автором, и это первый такой кейс из двадцати. Он же оказался щедрым: среди построенных скважин 99.8% уложились в два года, поэтому измеренное описывает факт постройки, а не соблюдение срока. Доля построенных в резерве 66.2% против 70.1% в окнах, и наблюдаемость исхода связана с назначенным бассейном — метрика описывает популяцию разрешений со ПРОСТАВЛЕННЫМ сроком, то есть 70% выданных.

## Что оценивается

положительным считается: постройка скважины наступает не позже, чем истечение разрешения. Сравнение без приведения грануляции. Отсутствие события по причине 'разрешение отменено', 'сведения в связанных квитанциях' означает 'excluded'. Отсутствие события по причине 'разрешение выдано, работы не начаты', 'разрешение истекло', 'срок разрешения продлён' означает 'not_occurred'. Отсутствие события по причине 'запрошена проверка после строительства', 'насос установлен, отчёта о строительстве нет', 'построена, но момент постройки не записан', 'разрешение истекло, насос установлен', 'скважина заброшена', 'состояние не записано' означает 'unobserved'.

Предложение собрано из направления, грануляции сравнения и смысла причин отсутствия события — то есть из тех же величин, по которым считается метка. Автор его не писал.
