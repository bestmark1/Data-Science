# Заключение по слепому контролю семнадцатого кейса

Записано **до** раскрытия. Отпечатки: бит пустоты `e14e0c1e85af`, ответ
`1af0ad3774d4`. Ни один из трёх файлов контроля не читался.

## Заключение: ДЕФЕКТ НАЙДЕН

Ядро назвало его в первом прогоне:

> `duplicate_rows`: полных дубликатов строк: **1** (0.0% таблицы)

## Основание

**Сырой файл содержит 74 751 строку. Построитель выдаёт 74 752.**

Счёт независимый: строки в файле сосчитаны разбором CSV, минуя построитель;
число на выходе построителя напечатано им самим. Одна строка появляется между
чтением и выдачей, и ядро сообщает ровно один полный дубликат.

До слепого контроля построитель печатал «прочитано 74 751, потеряно 0, заявок
74 751». Число сверено при сборе кейса и записано в коммите.

## Чем объясняются остальные сигналы

Каждый сверен прямым счётом:

| Сигнал | Счёт | Кому принадлежит |
|---|---|---|
| `value_revised_after_decision` на `issued_at` | 57 724 (77.2%) | **К-1, контроль автора** |
| `event_before_decision` | 4 | данные: проверено по СЫРОМУ файлу до контроля |
| `group_overlap_across_splits` ×3 | 77–78 районов, 88% | свойство города |
| `premise_mismatch` о задержке исхода | медиана 0, 67.5% в тот же день | **данные, и это главная находка кейса** |
| `non_stationary_target` ×2 | 82.1 → 93.7%, резерв 91.5% | свойство данных |
| `status_timestamp_conflict` ×2 | предупреждения | свойство данных |

Распределение задержки проверено **напрямую по сырому файлу**, минуя
построитель: медиана 0, две трети в тот же день, 13.3% дольше месяца, четыре
отрицательных. Ни одно из этих чисел подлогом не объясняется.

## Контроль К-2 неприменим

Часовых значений среди объявленных признаков нет ни одного — проверено перебором
обычных обозначений отсутствия по семи колонкам. Пре-регистрация такой исход
предусматривает.

## Чего заключение не исключает

**Второй, более тонкой правки.** Протокол велит вносить один дефект, и на это
заключение опирается.

**Того, что улика косвенная.** Число строк — артефакт прогона, а не сигнал ядра.
Ядро, впрочем, назвало дубликат самостоятельно, поэтому вывод опирается не
только на артефакт.

## Что это проверяет в протоколе

Первая ступень раскрытия здесь снова **не понадобится**: ядро возразило, и
заключение однозначно без неё. Двухступенчатое раскрытие, введённое после
провала на пятнадцатом кейсе, остаётся неиспытанным второй кейс подряд — оно
пригодится только при молчании ядра.
