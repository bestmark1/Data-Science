11 сентября 2026. Исполнитель проверки: существующая pi-панель `w2:p9`,
`openai-codex/gpt-6-astra`, thinking high. Координатор передал путь к проекту,
заданию и пользовательскому README без истории реализации, технического
отчёта и ожидаемых чисел. Агент сообщил, что в реализации не участвовал.

Координатор проверил список его обращений к файлам в pi-сессии
`01a08ab4-0754-77ae-a860-4d3266cdb4a8`: прочитаны общие инструкции,
само задание, README и собственные полученные артефакты. Других отчётов
приёмки и истории реализации среди прочитанных файлов нет.

## Фактическая работа проверяющего

Из корня проекта выполнено:

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python examples/synthetic-delay/run.py --out /tmp/ds-001-u.DJtRdv
```

Exit 0. Получены `report.md`, `findings.txt`, `measured.md`. Повтор в
`/tmp/ds-001-u-repeat.BkWgHL` также завершился exit 0; три отчёта совпали
побайтово, stderr второго запуска пуст. Координатор сравнил эти файлы.

Проверяющий самостоятельно объяснил один блокирующий сигнал на 4000
решениях, шесть пропущенных проверок, измерение на 483 строках резерва и
разные исходы сравнения: модель лучше ранжирует, постоянное правило лучше
калибровано. Отдельно отметил, что exit 0 означает завершение примера,
а не отсутствие проблем в данных.

Различение сигнала и доказательства выражено явно: сильная связь
`overrun_days` с исходом сама по себе не доказывает утечку. Происхождение
признака из исхода проверяющий принял из README и честно назвал его
самостоятельно не проверенным. Это соответствует границе критерия, а не
выдаёт сообщение инструмента за доказанный дефект.

## Ограничения, названные проверяющим

1. Синтетические числа не подтверждают качество на реальной задаче.
2. Сила связи не устанавливает момент доступности признака.
3. Пропуски проверок и вопросы владельцу оставляют непроверенные свойства;
   молчание не означает исправность.
4. Пример демонстрирует только binary/delayed.
5. Побайтовая повторяемость не подтверждает правильность расчётов;
   метрики, интервалы и силу связи он независимо не пересчитывал.

README признан достаточным для запуска и осторожного объяснения. Для
полного численного аудита проверяющий отметил отсутствие документированного
доступа к меткам/прогнозам и отсутствие списка признаков модели в отчётах.
Это предел этого прикладного примера; новую задачу на расширение сценария
координатор из этих замечаний не создаёт.
